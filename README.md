# StarsFabrica Bot

Telegram бот для продажи Telegram Stars через Fragment.

## Функционал

- 🌟 Продажа Telegram Stars пакетами (70, 100, 250, 500, 1000, 2500)
- 💳 Оплата через СБП (QRM)
- 🎁 Подарки звёзд другим пользователям
- 🤖 Автоматическая доставка через Fragment API
- 💎 Поддержка TON кошелька для транзакций

## Установка

```bash
npm install
cp .env.example .env
# Заполни .env своими данными
node app.js
```

## Команды бота

### Пользовательские

- `/start` — главное меню
- `70`, `100`, ... — выбор пакета звёзд
- `/gift <@username> <amount>` — подарить звёзды

### Админские

- `/last` — последние заказы
- `/session` — проверка сессии Fragment
- `/reauth` — инструкции по реавторизации
- `/deliver <order_id>` — ручная доставка заказа
- `/status <order_id>` — статус заказа
- `/freebuy <@user> <amount>` — тестовая покупка

## Требования

- Node.js 18+
- TON кошелёк с балансом
- Аккаунт Fragment с привязанным кошельком
- QRM API ключ для СБП
